Understanding password security

▦

Length vs. complexity

Every extra character multiplies the number of guesses an attacker must try, while adding a new symbol type only adds a fixed amount. A 20-character lowercase phrase can outlast a 10-character mix of every character type — length is the dominant factor in entropy.

◈

Passphrase memory benefits

A sequence of unrelated words is easier for a human brain to encode and recall than a random string, while still resisting dictionary attacks when the words are chosen independently and unpredictably — which is why this tool selects each word with a cryptographic generator rather than a pattern.

⛨

Credential isolation

Reusing a password across services means one breach exposes every account that shares it. Generating a unique credential per site — paired with a password manager — contains the damage of any single leak to that one account.
